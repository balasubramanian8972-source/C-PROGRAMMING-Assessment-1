QUESTION 4: DOLLARS AND CENTS

Question:
Help add two dollar-and-cent amounts. One dollar equals 100 cents. Input consists of four integers: the dollars and cents of the first amount, followed by the dollars and cents of the second amount. Write a C program to print the total dollars and cents.

Answer (C Program):
#include <stdio.h>

int main() {
    int d1, c1, d2, c2;
    int dollars, cents;

    scanf("%d %d %d %d", &d1, &c1, &d2, &c2);

    dollars = d1 + d2;
    cents = c1 + c2;

    dollars = dollars + cents / 100;
    cents = cents % 100;

    printf("%d\n%d", dollars, cents);

    return 0;
}

Sample Input:
30
10
140
99

Sample Output:
171
9
