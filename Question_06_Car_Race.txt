QUESTION 6: CAR RACE

Question:
The road is divided into three roads A, B, and C, each given a number. Given the numbers for roads A, B, and C and the number of cars, determine which road the car will travel on. If the car cannot travel on any road, display "No path exists".

Answer (C Program — provisional):
#include <stdio.h>

int main() {
    int a, b, c, cars;

    scanf("%d", &a);
    scanf("%d", &b);
    scanf("%d", &c);
    scanf("%d", &cars);

    if (cars % a == 0) {
        printf("Car 1 goes into road A");
    } else if (cars % b == 0) {
        printf("Car 1 goes into road B");
    } else if (cars % c == 0) {
        printf("Car 1 goes into road C");
    } else {
        printf("No path exists");
    }

    return 0;
}
